Project 3 · Decisions

An agent you can debug.

Deterministic final say

The rule-based scorer ranks every result, so the same request gives the same list and tests can pin it down.

Three retrieval modes

Structured filters, semantic search or a hybrid of both; the agent picks one per request.

A check, not blind trust

Confidence plus flags. Ask for a fake genre and it returns nothing at confidence 0.00, rather than a guess.

Built to fail safely

Capped retry loop, every LLM call logged, a templated fallback, and 24 offline tests with mocked LLM calls.

11

No vector database: the catalog is small, so simpler retrieval is easier to explain and maintain.
